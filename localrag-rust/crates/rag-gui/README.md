# LocalRAG Pro - GUI Application

eframe/eguiを使用したデスクトップGUIアプリケーション

## 概要

Rust製の高速デスクトップGUIで、Python版の全機能を実装:

- **モダンなダークテーマUI**
- **リアルタイム進捗表示**
- **ストリーミングチャット**
- **エージェントモード**
- **モデル選択UI**

## アーキテクチャ

```
src/
├── main.rs              # エントリーポイント
├── app.rs               # メインアプリケーション
├── backend.rs           # RAGバックエンド処理
├── state.rs             # アプリケーション状態管理
└── ui/
    ├── sidebar.rs       # サイドバーUI（設定、インデックス管理）
    └── chat.rs          # チャットUI（メッセージ、入力）
```

## 主な機能

### 1. サイドバー

- Ollamaステータス表示
- LLM/Embeddingモデル選択
- フォルダ選択
- インデックス作成（進捗バー付き）
- 統計情報表示

### 2. チャットエリア

- メッセージ表示（ユーザー/アシスタント）
- ストリーミング応答
- ソース情報表示
- エージェントモードトグル
- テキスト入力エリア

### 3. バックエンド

- 非同期RAG処理
- mpscチャネルでUI通信
- 進捗レポート
- エラーハンドリング

## ビルド & 実行

```bash
# 開発ビルド
cd localrag-rust
cargo run -p rag-gui

# リリースビルド
cargo build --release -p rag-gui

# 実行ファイル
./target/release/rag-gui
```

## 必要要件

1. **Ollama実行中**
   - LLMモデル（例: gemma2:2b, qwen2.5:7b）
   - Embeddingモデル（例: nomic-embed-text）

2. **ChromaDB実行中**（ローカルホスト:8000）

## 使い方

### 1. モデル設定

- サイドバーでLLM/Embeddingモデルを選択
- Ollamaで利用可能なモデルが自動表示

### 2. インデックス作成

1. 「📂 フォルダを選択」でドキュメントフォルダ選択
2. 「⚡ インデックス作成」をクリック
3. 進捗バーで処理状況を確認

### 3. 質問

1. チャットエリアの入力欄に質問を入力
2. Enterまたは「→」ボタンで送信
3. ストリーミング応答がリアルタイム表示
4. ソース情報が下部に表示

### 4. エージェントモード

1. 入力欄横の「🤖」トグルをON
2. 自律的にキーワード抽出して並列検索
3. 進捗状況が表示される

## UI カスタマイズ

### カラースキーム

```rust
// メインアクセントカラー（青）
Color32::from_rgb(79, 195, 247)

// 成功（緑）
Color32::from_rgb(76, 175, 80)

// エラー（赤）
Color32::from_rgb(244, 67, 54)

// 警告（黄）
Color32::from_rgb(255, 193, 7)

// 背景（濃灰）
Color32::from_rgb(36, 36, 36)
Color32::from_rgb(48, 48, 48)
```

### フォントサイズ

- タイトル: 24px
- ヘッダー: 14-16px
- 本文: 14px
- キャプション: 11-12px

- **メモリ使用量**: 100-150MB（Python版の1/3）
- **UI応答性**: 60fps（eframe/egui）
- **ストリーミング遅延**: 100ms未満

## トラブルシューティング

### Ollamaに接続できない

- Ollamaが実行中か確認: `ollama list`
- デフォルトポート（11434）が使用可能か確認

### ChromaDBに接続できない

- ChromaDBが実行中か確認
- ポート8000が使用可能か確認
- 環境変数 `CHROMA_URL` で接続先を変更可能

### ビルドエラー

```bash
# 依存関係更新
cargo update

# クリーンビルド
cargo clean
cargo build -p rag-gui
```
